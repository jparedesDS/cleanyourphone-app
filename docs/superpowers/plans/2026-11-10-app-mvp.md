# CleanYourPhone App MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a Windows-only, guided PySide6 app that safely applies an exact CleanYourPhone device profile, backs up first, verifies in batches, and links unsupported phones to the skill website.

**Architecture:** A native PySide6 window drives a frozen `cleanyourphone` CLI sidecar built from the pinned `v0.2.2` tag. The app reads `--json probe`, `--json plan` and `--json verify`, writes through `backup`/`disable`/`restore`, and keeps one ADB transport per session. ADB is acquired from Google on first run, not redistributed.

**Tech Stack:** Python 3.12, PySide6 6.8+, pytest, pytest-qt, PyInstaller, Inno Setup 6, GitHub Actions on `windows-latest`.

**Spec:** `docs/superpowers/specs/2026-11-10-app-mvp-design.md`

## Global Constraints

- Windows 10/11 x64 only; app version `0.1.0`; CLI sidecar pinned to `v0.2.2`.
- Python `>=3.12`; PySide6 `>=6.8,<7`; no web view, no local server, no Electron/Tauri.
- The app never calls `adb` for package changes. Every write goes through the CLI.
- Only exact `verification: device` profiles with a build in `tested` may reach Review/Apply.
- No backup means no changes. No skip/ignore control.
- `DISABLE` rows checked by default; `ASK` rows unchecked by default.
- Batches are at most five packages. The CLI verifies and attempts rollback after each batch.
- One ADB transport per session; no mid-session USB/Wi-Fi switch.
- Undo restores the whole CleanYourPhone journal for that phone and says so.
- No telemetry, no account, no cloud. The only network request is the user-initiated Platform-Tools download.
- Spanish and English are both first-class; missing package translations fall back to English visibly.
- The app never claims “sin fallos” or “100% safe”. The copy is “si algo no cuadra, no se cambia nada y puedes deshacer”.
- The app source is MIT; PySide6/Qt notices are included in the installer.

## Review Focus

- A phone reconnects with a different ADB serial; undo must not fail silently or claim there is nothing to restore.
- The CLI refuses after the app has allowed a phone (OTA/build change); the app must stop before any write.
- Platform-Tools download hash mismatch or offline state; the app must never execute unverified adb.
- A batch verification fails and rollback is partial; the app must show the actual remaining disabled packages, not claim the phone is unchanged.
- A package has no Spanish translation; the row must show English with a visible “Detalles en inglés” fallback, never blank text.
